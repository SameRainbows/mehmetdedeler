# mehmetdedeler.com

The personal site of [Mehmet Dedeler](https://mehmetdedeler.com): one HTML page, no JavaScript. Served by Cloudflare Workers.

```bash
npm install
npm run dev      # http://localhost:3000
npm run deploy   # build and publish
```
